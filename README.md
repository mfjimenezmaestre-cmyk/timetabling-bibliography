# Timetabling Bibliography

This repository contains a curated BibTeX bibliography of key papers, surveys, benchmarks and tools for automated timetabling (course/exam timetabling, heuristics and metaheuristics).

Files included:
- `references_timetabling.bib` — BibTeX file with surveys, classic papers, benchmarks and links.

How to download
- Download the raw BibTeX file directly: https://raw.githubusercontent.com/mfjimenezmaestre-cmyk/timetabling-bibliography/main/references_timetabling.bib
- Download the entire repository as a ZIP (main branch): https://github.com/mfjimenezmaestre-cmyk/timetabling-bibliography/archive/refs/heads/main.zip
